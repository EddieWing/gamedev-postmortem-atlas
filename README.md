# Gamedev Postmortem Atlas: веб-версия

Готовая статическая страница. Сборка и сервер не нужны: всё работает из папки, в том числе если открыть `index.html` двойным кликом.

## Что в папке

```
index.html          страница: заголовок, вводный текст, фильтры, подвал
assets/atlas.css    стили; все правила внутри класса .pca, поэтому они не задевают остальной сайт
assets/atlas.js     логика: фильтры, раскрытие карточек, ссылки на конкретную игру
assets/cases.js     данные: 527 игр и 706 решений
covers/*.webp       горизонтальные капсулы 460×215, грузятся только для показанных карточек
```

## Как поставить на сайт

**Отдельной страницей.** Скопируйте папку целиком, например в `/atlas/`. Страница откроется по адресу `ваш-сайт/atlas/`.

**Внутри существующей страницы.** Перенесите в неё четыре вещи:

1. В `<head>`: ссылку на шрифты Google Fonts и `assets/atlas.css` (обе строки есть в `index.html`).
2. В `<body>`: весь блок `<div class="pca" data-pca> … </div>` из `index.html`.
3. В конец `<body>`: `assets/cases.js`, затем `assets/atlas.js`, в этом порядке.
4. Если обложки лежат не в папке `covers` рядом с `assets`, укажите путь до подключения скриптов:

```html
<script>window.PCA_CONFIG = { coversPath: '/static/atlas/covers/' };</script>
```

Блок занимает ширину до 920 px и сам держит отступы по бокам. Фон и цвета задаются внутри `.pca`, так что страница-хозяин может иметь свой фон.

## Настройки

`window.PCA_CONFIG`, если задать до `atlas.js`:

- `coversPath`: папка с обложками.
- `reportEmail`: адрес, на который уходят сообщения «See a mistake? Report it». Кнопка открывает у читателя почтовое приложение с уже заполненным письмом: игра, решение, ссылка на карточку и его текст. Пока адрес не задан, кнопка копирует текст сообщения в буфер.
- `reportUrl`: вместо почты можно указать страницу формы (например Google Form). Тогда текст сообщения копируется, и форма открывается в новой вкладке.
- `pageSize`: сколько игр показывать до кнопки «Show more games», по умолчанию 30.

Панель фильтров прилипает к верху экрана при прокрутке. Если у сайта есть своя закреплённая шапка, задайте её высоту, чтобы панель вставала под неё:

```css
.pca { --pca-sticky-top: 64px; }
```

Тема следует системной. Чтобы закрепить одну, добавьте блоку `data-theme="light"` или `data-theme="dark"`.

## Как устроена карточка

В шапке карточки название игры, студия и год, под обложкой масштаб (AAA, AA, Indie, Solo). Клик по карточке раскрывает её, клик по шапке раскрытой карточки сворачивает. Клик по обложке открывает страницу игры в магазине (Steam, GOG, Nintendo, PlayStation, App Store или сайт игры). У каждого решения в списке стоит итог: Backfired, Paid off или Tradeoff. В раскрытой карточке первое решение открыто сразу, остальные раскрываются кликом по строке. Ссылка на источник ведёт к месту цитаты, где это возможно: для статей через текстовый фрагмент, для видео через отметку времени.

Кнопка «I'm lucky» рядом с поиском открывает случайное решение из того, что сейчас видно с учётом фильтров.

## Ссылки на конкретную игру

У каждой игры есть якорь: `ваш-сайт/atlas/#pca-hellbladesenuassacrifice` открывает атлас сразу на этой карточке. Ключ игры виден в адресной строке после раскрытия карточки. Это удобно для слайдов и постов.

## Без JavaScript

Если скрипты отключены, страница показывает простой список всех игр и решений со ссылками на источники. Этот же список видят поисковые роботы.

## Что стоит добавить на своей стороне

- `<link rel="canonical">` и `og:url` с адресом, где будет страница.
- Картинку для превью в соцсетях (`og:image`).
- Счётчик аналитики, если он есть на сайте.

## Обложки

Взяты из магазинов: Steam (горизонтальная капсула со страницы игры, ID каждой игры сверен с названием в Steam), страницы Nintendo, PlayStation, GOG, App Store и сайты игр. У игр без страницы в магазине (в основном отменённые проекты) вместо обложки стоят инициалы.
